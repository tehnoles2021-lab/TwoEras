# Demo Website for Short-Term Apartment Rentals

This project is an example of my work in creating modern, fast, and responsive websites. I have developed a complete landing page for a rental business using only static technologies, which ensures high loading speed and ease of maintenance.

The site is available at: [https://tehnoles2021-lab.github.io/TwoEras/](https://tehnoles2021-lab.github.io/TwoEras/)

## About the Project

The site serves as a showcase for apartments available for daily rent. The main goal is to attract customers through search engines and provide a comfortable browsing experience for property information. I have implemented:

- Bilingual support (Russian/English) with separate URLs for each version, which is important for SEO.
- Fast loading thanks to minimalistic code and resource optimisation.
- Responsive design that displays correctly on all devices – from smartphones to widescreen monitors.
- A convenient feedback form integrated with an external service for receiving enquiries.
- Basic SEO optimisation: robots.txt, sitemap.xml, meta tags.
- Installed analytics (Yandex Metrica) to track user behaviour.

## Technologies Used

- Pure HTML5, CSS3 and JavaScript – no frameworks, ensuring lightness and full control over the code.
- GitHub Pages for hosting – fast and free deployment.
- External services for form processing and statistics collection.
- BEM methodology for organising CSS classes (if applicable).

## Implementation Highlights

- Responsive layout using media queries.
- Cross-browser compatibility.
- Optimised images (converted to WebP for faster loading).
- Semantic markup for better search engine indexing.
- Well-structured project code, easy to modify and scale.
