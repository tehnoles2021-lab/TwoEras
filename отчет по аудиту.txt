### 🛠️ Технические замечания по сайту

**1. FormSubmit.co — потенциальная угроза для бизнеса**

Это самый критичный момент. Сервис, который вы используете для сбора заявок, имеет крайне низкий рейтинг доверия (30 из 100). Многие антивирусы и системы безопасности вносят его в чёрные списки.

Из-за этого:
*   **Браузеры могут блокировать отправку форм** с вашего сайта, и вы потеряете заявки.
*   **Почтовые сервисы** могут помечать письма от FormSubmit как спам.
*   **Пользователи** могут увидеть предупреждение о небезопасном сайте.

Рекомендация: **немедленно замените FormSubmit.co** на надёжное решение. Для вашего сайта на GitHub Pages отлично подойдут бесплатные аналоги:
*   **Formspree**: Простой и проверенный сервис, у которого есть бесплатный тариф.
*   **Getform.io**: Также поддерживает бесплатный план и хорошо интегрируется со статическими сайтами.

**2. Структура EN-версии — поисковики её не видят**

Вы абсолютно правы: скрывать английскую версию через `display: none` — плохая практика для SEO. Поисковые роботы не индексируют скрытый контент.

Рекомендация: сделайте для EN-версии отдельные URL. Например:
*   `https://tehnoles2021-lab.github.io/TwoEras/` — русская версия.
*   `https://tehnoles2021-lab.github.io/TwoEras/en/` — английская.

Это позволит индексировать обе версии и показывать их в поиске соответствующей аудитории.

**3. robots.txt и sitemap.xml — вопрос реализации на GitHub Pages**

Создать эти файлы — правильно, но для GitHub Pages есть нюанс: они должны лежать **в корне вашего репозитория**, чтобы быть доступными по адресам `https://tehnoles2021-lab.github.io/robots.txt` и `https://tehnoles2021-lab.github.io/sitemap.xml`.

В sitemap.xml обязательно укажите все значимые страницы, включая будущие версии на английском.

**4. Установка Яндекс.Метрики**

Всё верно, её нужно установить как можно скорее. Для GitHub Pages код счётчика можно добавить:
*   Непосредственно в HTML-файлы (в секцию `<head>`).
*   Если вы используете шаблонизатор или генератор статики — в соответствующий базовый шаблон.
*   Через систему управления тегами, например, Google Tag Manager.

Главное — после установки обязательно проверьте, передаются ли данные в Метрику.
